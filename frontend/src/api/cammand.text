Redesign the existing Settings page UI/UX into a modern, premium split-layout design while preserving ALL existing functionality, API integrations, state management, validation, and backend behavior.

IMPORTANT:
Do not rewrite or break the existing settings logic.
This task is primarily a FRONTEND UI/UX redesign.

CURRENT DESIGN:
The Settings page currently has:
- Appearance section with Light / Dark / System
- Preferred currency dropdown
- Language dropdown
- Email notifications checkbox
- Budget alerts checkbox
- Save changes button
- Account Management section
- Manage account button

The current page is a centered single-column layout.

NEW DESIGN DIRECTION:
Transform it into a two-column split experience.

==================================================
1. OVERALL LAYOUT
==================================================

Create a responsive two-column layout:

LEFT SIDE:
The actual Settings content should remain the primary focus.

RIGHT SIDE:
Add a visually attractive finance/productivity-themed visual area containing subtle animations/effects.

Desktop layout:

--------------------------------------------------
|                                                |
|  SETTINGS CONTENT       |    VISUAL AREA       |
|  LEFT / 55-60%          |    RIGHT / 40-45%    |
|                         |                      |
|  Appearance             |   animated visual    |
|  Preferences            |   / illustration     |
|  Notifications          |                      |
|  Account management     |   finance-themed     |
|                         |   decorative effects |
--------------------------------------------------

The left side should be slightly wider than the right side.

The page should feel balanced, spacious and premium.

Do NOT make the right side overpower the actual settings.

3. RIGHT VISUAL AREA
==================================================

Create a modern finance/productivity visual that complements an expense tracking application.

Preferred visual concept:

A floating financial dashboard / abstract money-management illustration.

For example:

- Floating expense cards
- Small transaction cards
- Circular spending chart
- Animated percentage indicator
- Small wallet/money icon
- Floating coins/shapes
- Abstract gradient blobs
- Subtle glowing circles
- Small upward/downward financial indicators
- Decorative grid or dots

The visual should communicate:

"Organize your money. Understand your spending. Stay in control."

Do NOT use a generic stock image.

Prefer a CSS/SVG-based illustration or lightweight React component so that:
- No external image dependency is required
- It loads quickly
- It matches the application's brand
- It can animate smoothly

If an illustration/image is used, keep it minimal and modern.

==================================================
4. ANIMATION
==================================================

Add subtle premium animations.

The animation should feel similar to a modern SaaS/product landing page.

Examples:

- Floating cards slowly moving up/down
- Decorative circles gently floating
- Chart elements appearing with slight delay
- Soft pulse/glow effect
- Very subtle rotation of decorative elements
- Fade/slide entrance when page loads
- Hover interaction on visual cards

Animation principles:

- Smooth
- Slow
- Elegant
- Not distracting
- No excessive bouncing
- No flashy effects

Use CSS animations or Framer Motion ONLY if Framer Motion already exists in the project.

Do not add a new heavy dependency just for animation unless necessary.

Respect prefers-reduced-motion.

If the user has reduced motion enabled, disable or significantly reduce non-essential animations.
